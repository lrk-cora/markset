# 侧栏开合中断正在运行的任务：2026-10-07

## 可复现原因

`main.js` 的 `render` 在检测到笔迹布局投影变化时，曾对未完成任务执行 `cancelModelAnalysis`、增加 group revision、转回 draft 并 `scheduleAnalysis`。侧栏改变 iframe 宽度后，`markset:page-layout` 触发这个分支；它把纯布局变化当成新用户笔迹，从而取消、重启分析。手动分析模式下则可能被取消而不自动恢复。

控制器回归在修复前直接失败：打开侧栏对应的布局事件使原请求的 AbortSignal 变为 aborted。

## 修复

- 响应式重排仅投影笔迹、目标和现有方案。保留语义 revision、任务、分析时钟、输入、Agent 记录和原有停笔队列；不排队新模型请求。
- 准備截图时从相同用户操作的当前几何采集结构、区域、截图及笔迹。若截图因布局变化失效，最多重新准备一次本地截图，共用原 8 秒截止时间，不重复模型调用。
- 返回的模型方案从其证据快照投影到当前布局后再做原有校验。批量步骤、候选方案及图片位置一起适配；发布前同步显示几何，避免二次缩放。
- 图片生成及最终隔离校验保持同一个 applying 操作。生成期间开合侧栏不丢弃图片、不重新生成。
- 如果校验等待期间布局又改变，最多重做一次本地校验，同一个图片资源及确认授权继续使用。仍不稳定则安全停止，不把视口变化当作坏设计发起付费方案修复。
- 真正的新笔迹、取消、选区变化仍使旧请求失效；影响范围、确认、隔离试执行及撤销校验没有放宽。

## 验证

- 410 项自动测试通过，构建通过。新增覆盖：运行中分析保留、延迟图片方案定位、生成与最终校验期间重排、截图本地重试、重复不稳定布局、批量与候选计划、取消、修复策略。
- 独立 Chrome 的 13 项断言通过：在等待模型回复时打开 Agent 侧栏，记录仍为一次操作，revision 和分析开始时间不变；在等待图片时收起侧栏，最终位置对应新宽度；仅一次模拟分析及一次模拟生图，原文保留，一次撤销恢复完整原文。
- 最终实测图片矩形约 `(728.64, 107, 371.05, 266)`，重排方案矩形约 `(728.64, 107, 371.04, 266)`，各项差异小于 4 像素。
- 浏览器使用受控响应与简洁响应式 HTML，未调用真实付费模型。没有终止或替换用户的本地终端服务；已确认 localhost:5173 提供更新后的代码。

测试针对侧栏重启及任务几何一致性，不代表每种导入网页的布局方案都能通过既有遮挡校验，或模型上游延迟已消失。

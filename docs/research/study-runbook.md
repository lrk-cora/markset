# Markset 研究试跑手册

适用 markset-pilot-v2。此版本用于先导准备，尚非“除正式实验外全部完成”的投稿版本；主稿见 [UIST 工作稿](./uist-manuscript.md)。

## 1. 验证与保存版本

在项目目录执行：
```powershell
npm test
npm run build
npm run test:browser
npm run evaluate:corrections
npm run study:prepare
```

前四项工程验证不触发付费模型。浏览器测试会复用已有 localhost:5173；未启动时按配置启动测试服务器，不结束用户已有服务。study:prepare 生成 public/study/tasks 的 12 页及素材清单，并保存 output/study/freeze.json（被 Git 忽略）。白名单含源文件、UI、测试、脚本、研究文档和依赖清单，不读取 .env、Key、私有素材或用户导出。

不要以 HEAD 代替工作区：清单同时保存当前源文件哈希。请单独保留批次清单和不可变代码副本，另外记录非敏感配置：
- 实际规划模型 ID/服务版本、地域、采集日期（不能自动固定远端别名）。
- 分析总时限、前端等待、查证/重试预算、模型参数及提示/工具哈希。
- 设备、Chrome 版本、固定视口、任务顺序及费用上限。

不要复制整个工作目录或 .env 当复现包。密钥、日志和身份表不提交 Git。清单是溯源辅助，不是自动完成预注册或配置冻结。

## 2. 从界面启动一轮

1. 用户原有开发服务可继续使用；如尚未运行，自行在本地终端执行 npm run dev，Ctrl+C 可自主关闭。本轮没有接管或重启用户服务。
2. 右侧「Agent 记录」展开「对照评估 · 本地记录」，结束现有标记和会话。
3. 任务编号填 T1A 至 T6B，点击「载入固定任务页」。它不覆盖保存的个人导入网页；刷新恢复个人导入页是预期行为，不恢复研究同意。
4. 选择研究条件，填 P00 试跑编号（真实研究用分配编号），勾同意再开始。
5. 纯文字在右侧输入目标并点击分析；矩形在网页拖出多个框，再填写关系目标；笔迹开启画笔并标记，再主动「开始分析」。
6. 分析后默认不改网页。检查实际对象、范围和位置，再单独点击「修改」。需要撤销可用顶部按钮。

当前模型配置仍用 Flash；这不是在切换 Codex 自身。**正常分析仍可产生已配置服务的费用**，本次自动测试则已全部拦截，无付费调用。

## 3. 恢复任务

只在 ink-correction / ink-no-correction 运行，先按同样程序标记相关模块。例如 T3/T6 涉及左右标题，先把两个相关区域纳入证据；只有左模块的观察不能强行注入右侧错对象。

点击「展示本任务预置错误建议」。来源明确为非模型调用、错误展示事件自动记录、网页不改；若目标不在证据中会拒绝注入。没有已有要求时，冻结目标作为初始要求保留，纠正后不必重述；已有输入不会清空，正式比较应统一初始要求。没有保存纠正后反复覆盖的入口，也不会覆盖正在运行的分析。

- 直接纠正：展开检查器，修改对象/角色/唯一短语/相对锚点后保存。旧方案整份失效；等待也不会自动发请求，须点击开始分析。
- 文字补充：同样能查看理解，纠正控件禁用；用普通要求框重述并主动分析。
- 自然错误：观察员可标记首次真正看到的错误。不要把系统返回时刻或 session-start 当成看见错误的时刻。

T1 固定页使用同一测试 SVG，模型位置不自动修正，仍需真实应用/撤销；不会请求图片生成。其他真实生图或原图编辑不属于这项隔离测试，须单列明确启动。

## 4. 结果、评分与导出

最终结果导出 HTML，保存为经同意的研究材料；分享给评分者时去掉条件、身份和不必要日志。结构辅助：
```powershell
npm run study:score -- T1A "C:\study\P01-T1A-final.html"
npm run research:analyze -- "C:\study\markset-research-events.json"
```

结构检查只能覆盖部分节点/字符/位置，不评价全部属性、布局、语义或审美，输出里 visualQuality 与 overflow 保持 null。独立评分员按判据记录目标、保留、位置/范围和溢出；角色选择、Apply、撤销成功都不是任务正确性。

在展开的评分入口填 R01，保存最终结果；每轮控件会重置。实际双评分、盲法和分歧裁决另保管独立表，不能把界面一份评分当成已完成方法。参与者报告的负担和可控感是 1–7 分单项，0 为未收集，不称 NASA TLX。

停止后导出元数据 JSON，并核对任务/条件/编号、展示起点、输入/等待/失败与实际观察是否一致。请求发出次数与已返回的模型调用统计分开；取消或未完成分析可能缺失上游调用数，不能当作零费用。返回结果附带结构证据字符数、图片数量和查证次数。最多 5000 条，应逐批导出，不能等截断后再补。评分后修改或撤销会使旧评分失效，需重新评最终状态。

- 侧栏重排不重新规划；固定图片放置与整体撤销。

不能据此复现人类效益或真实模型总体质量：目前没有正式参与者数据。接下来先核查矩形基线、难度、更多独立布局及采集/评分流程，再按伦理、预注册和预算开展真实评估。

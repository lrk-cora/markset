# Markset 纠正机制与试跑工具进度

更新日期：2026 年 10 月 8 日。本阶段交付最小纠正闭环与对照试跑工具；不声称模型质量、条件公平性或人类收益已得到验证。

## 最小纠正闭环

1. 标记网页，主动分析并获得建议，按需展开「查看并纠正理解」。未分析的手动标记也能检查绑定。
2. 在合法相关证据中选择实际对象或模块，设置参考、可修改、保留或放置角色；选择会联动高亮。
3. 局部文字可粘贴原文中唯一出现的片段。UTF-16 范围只支持替换或删除；重复、截断与过期片段拒绝绑定，不猜测第一处。
4. 指定合法锚点和内部开头、内部末尾、前面或后面；没有端点拖拽或任意坐标编辑器。
5. 保存纠正使整份旧方案、预览及授权失效，取消旧请求，保留笔迹、输入及符合原提示/原图指纹的资源。保存本身零模型调用，不自动分析或修复。
6. 主动「开始分析」，完整新方案经过检查后再「修改」；顶部撤销回滚整体事务。

「保留内容」允许保留原文的配色、必要布局及新增；「仅作参考」禁止直接写入，除非另一处明确授权对应子对象。选中模块不等于替换整个模块，也不禁止模块内部新增。

## 约束与边界

- 前后端共享纠正规范和约束，合理目标不会因不属于主题按钮而降级；格式、引用或严重执行错误仍阻止应用。
- 稳定区域 ID 用于绑定，显示数字按位置变化；标记组修订、绑定版本和内容快照阻止过期、晚到方案。
- 快照关注文字、原图、父节点等语义信息，不包含视口或像素尺寸。侧栏展开更新覆盖层，不重启请求。
- 本版保守地整份方案失效，不冒充细粒度依赖图或独立性证明。
- 不包含完整可拖拽关系图、字符拖选、箭头端点拖拽；论文已收窄为表单式最小机制。
- 隔离检查是有限执行检查，不证明语义或审美正确。

## 五种条件，分开回答三个问题

| 问题 | 比较条件 | 当前差异 |
| --- | --- | --- |
| 输入表达 | text-only / selection-text / ink-no-correction | 无选区文字 / 独立矩形选择与文字 / 原始笔迹与文字；均无直接纠正 |
| 直接纠正 | ink-correction / ink-no-correction | 同样笔迹、证据与查看反馈，前者额外开放纠正表单 |
| 结构证据增强 | ink-no-correction / ink-flat-evidence | 后者去掉规划器和只读查证中的预计算模块层级及端点候选 |

这些入口不是已经证实的公平基线。三种输入可以使用相同配置模型、工具和请求预算，保留查看、补充、检查、确认和撤销。研究会话统一关闭停笔自动分析、个人习惯及本地快捷执行；不会因条件不同静默升级模型。文字条件可查看方案对象，明确标为非用户选区，不能回传成选中证据。矩形选择独立保存几何与对象，不伪造手写笔迹；可通过多个矩形和文字指代目的地。

扁平证据仍保留截图、原始笔迹、节点 ID、内容、坐标和样式，模型可自行推断关系。执行安全仍使用完整合法证据。因此它只是结构证据增强消融，不是完整角色表示消融，也不是取消安全保护。真实输入量、截图、查证和响应等待的差异需要记录、试跑和解释。

## 任务、注入、记录和评分

- 六类任务，每类 A/B 两个内容变体，共 12 页；共用一个两栏骨架，不是 12 个独立布局，也未证明等难。
- 显式载入 T1A 至 T6B，不覆盖保存的个人导入页。只有匹配已载入任务的会话才能展示冻结错误。
- 预置错误来源明确标为非模型调用；先检查其对象在合法证据内，不绕过检查，不自动应用。
- T1 固定插图任务采用同一代码绘制 SVG 资源，实际放置及撤销仍走执行器，不请求生图。仅用于位置与恢复，不测图片质量。
- 事件记录默认关闭、每轮取得同意；匿名编号 P01，身份表另存。刷新不恢复记录。
- 本地日志只保存白名单元数据，不保存原文、输入、完整笔迹、截图或完整模型输出，也不发送给模型。最多 5000 条，定期导出；存储失败仍可导出内存记录。
- 错误展示、文字提交字符数/补充次数、纠正、请求发出、已返回的模型调用/重试、结构证据字符数、图片数量、查证次数、应用、失败、撤销、取消及人工评分可记录。取消或未完成分析的调用统计标为可能不完整，不据此估计全部费用。每轮评分控件重置；评分后又修改或撤销，旧评分失效。
- HTML 结构评分器只是辅助，不提供审美、语义或完整布局保证。Apply 和“错误至 Apply”不能当作目标达成或成功恢复。

命令与步骤见 [试跑手册](./study-runbook.md)，研究设计见 [对照协议](./correction-study-protocol.md)。冻结脚本只读取源文件和材料白名单，输出哈希；不读取、复制或提交密钥与 .env，不自动固定远端模型版本或证明 Git HEAD 包含未提交改动。

## 工程验证（不是用户实验）

- 475 项 Node 回归通过（含 12 项首次运行配置与密钥保护检查）。
- 23 项真实浏览器测试通过；1 项报告 HTML 未配置而跳过，不计作通过。
- 生产构建通过，仍有既有单包超过 500 kB 提醒。
- 14 个固定方案契约案例全部符合预期：5 个正确事务应用并撤销，9 个违规事务被约束阻止。
- 新浏览器走查覆盖纯文字无选区、矩形无伪造笔迹、只读查看、显式应用和撤销、侧栏无重新分析、预置错误来源、保存纠正零调用、旧方案失效，以及 T1 固定资源真实位置。
- 全部本阶段验证用受控响应或本地执行，零付费模型调用、零参与者。不得把测试通过率写成模型准确率或恢复收益。

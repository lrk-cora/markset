# 画布修复与验证记录

## 已定位并修正的路径

- 原先在抬起时先检查 `drawing`，之后才记录抬起坐标。只有 down/up、没有 move 的快速划线被当作空白点击，主程序因此清空整组笔迹。
- 原先 28px 的最短距离会丢掉短线和箭头头部。现在点击阈值为 3px，是否存储不再依赖闭合区域、目标命中或手势类别。
- 原先只在松笔时中止前一轮分析。现在按下就取消定时分析和模型请求，绘制时隐藏建议，松笔后重新计时。
- 移除用 SVG 节点和笔迹子集来猜测状态新旧的逻辑。修改组是唯一权威数据；分析按组 ID、revision 和请求序号校验，不能写入 strokes。
- 恢复在真实页面元素上进行 pointer capture；处理中断、失焦、丢失捕获、缺失 mouseup 和多指干扰。原始笔迹在识别前保存。
- 原箭头规则把大于 90px 的直线直接当作箭头。现在必须有末端箭头头部证据；横线不再自动变成重排指令。
- 文件导入 input 保持在文档中直到选择/取消完成，避免文件选择器找不到节点。

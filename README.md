# MarkSet

混排页上的跨模态选区实验。一次套索同时圈到**字**和**图中物体**，盖上 `#T1` `#I2`，用同一排工具条发命令。

本仓库只放可运行代码，方便单独推到 GitHub。

## 第 1 周范围

已实现：

- 写死的商品介绍混排页（TipTap，不可直接打字）
- `Alt` + 拖 **套索**（多边形命中，不做框选）
- 字：字符区间 + 按行蓝条高亮
- 图：套索轴对齐外接矩形当 mask（手势仍是套索）
- 篮子、名牌、工具条（有图才出三支笔）
- 单击补选、`Shift` 套索追加、`Esc` 清空

未接模型。改写 / 重绘 / SAM / 规划是第 2–3 周的事；工具条按钮目前只提示周次。

## 本地运行

需要 Node.js 18+。

```bash
cd markset
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 <http://localhost:5173>）。

## 手势

| 操作 | 作用 |
|---|---|
| `Alt` + 拖 | 套索。松手后命中字和图 |
| 单击词 / 图 | 补选进当前篮子 |
| `Shift` + 套索 | 追加，不清空篮子 |
| 点名牌 | 指定命令只打在这一块；再点或点 × 踢出 |
| `Esc` | 清空篮子 |

拖套索时页面不滚动、不发请求。

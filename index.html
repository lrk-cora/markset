MarkSet 圈画批注后导出网页

导入网页前

MarkSet 怎么用

圈画批注，判断后改网页，导出去掉标记。

基本流程

  1. 导入 HTML
  2. 画好后点 开始判断
  3. 选择操作
  4. 导出网页

圈选和标记

  • 偏好记错：管理偏好 或 标记偏好
  • 重新框选：清笔迹再画

快捷键

Shift + 圈
加选
Alt + 圈
减选
Esc
取消当前笔画；再按清空
Backspace
擦上一笔
Ctrl / ⌘ + Z
撤回修改

顶栏「加选」「减选」同快捷键。

选中列表

用画笔涂过要改的字或图，再在旁边手写一两个字。系统按写下的字推测操作，由你点选。写错可擦掉重写。认不出时仍给通用项。价格、物流不改。
